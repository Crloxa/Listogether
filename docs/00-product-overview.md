# 产品概览

## 目标

让朋友通过一个互联网链接进入同一个音乐房间，听到房主本地播放的音频，并以统一的歌曲、进度和队列状态进行互动。

## 不做什么

- 不把音频上传到云端永久存储。
- 不收集音乐平台密码，不在邀请链接中携带 token。
- 不绕过平台会员、DRM、地区限制、CORS 或其他访问控制。
- 不在 MVP 引入账号社交网络、公开房间发现、推荐算法或语音通话。

## 用户角色

| 角色 | 能力 |
| --- | --- |
| 房主 | 创建/关闭房间；播放、暂停、拖动、切歌；管理队列和成员；授权本地音频分享 |
| 共同 DJ | 在房主授权后管理队列和切歌；不能转移房间所有权，除非明确授权 |
| 听众 | 加入、收听、点歌、投票、聊天；独立音量/静音/重新同步 |

## 核心流程

1. 房主启动本地应用，创建带随机 token 的房间。
2. 房主复制链接或二维码邀请好友；好友通过互联网连接中继服务并加入。
3. 房主导入本地文件或添加可用来源，系统展示标题、艺人、时长、封面和来源状态。
4. 房主播放、暂停或拖动进度时更新房间状态；只有切换下一首时进入全员准备同步状态。
5. 房主切换下一首时，在线成员缓冲新歌曲并上报 ready；达到屏障后按统一开始时间播放。
6. 迟到成员不自动追赶当前歌曲，只显示状态提示和“重新同步”按钮。
7. 成员点击“重新同步”时，只修复自己的播放状态；不改变房间其他成员。

## MVP 功能边界

- 房间创建、链接邀请、昵称、人数上限、密码、锁房、踢人和房主转移。
- WebSocket 控制/信令通道、WebRTC 房主到成员的音频流。
- 播放/暂停/拖动/上一首/下一首、顺序/单曲/随机、空队列和失败处理。
- 播放列表、点歌、审批、投票跳过、去重、冷却时间、请求历史和撤销。
- 本地文件拖入、文件夹导入、标签/封面读取、来源状态和临时流式分享。
- 官方 OAuth（Authorization Code + PKCE）、最小权限、token 安全存储和撤销入口。
- 断线重连、手动重新同步、下一首准备屏障和统一开始时间。
- 聊天/反应、收藏、历史、歌单导入导出、媒体键和移动端适配可在 MVP 闭环稳定后接入；是否纳入当前交付由阶段验收决定。

## 非功能目标

- 任何单个成员掉线都不应泄露房主文件路径或阻塞全房间无限等待。
- 房间状态消息具有递增版本，旧消息不能覆盖新状态。
- 失败原因可见、可重试、可定位；日志不含密钥和个人文件内容。
- 同一房间的基础操作在桌面主流浏览器可重复验证。
